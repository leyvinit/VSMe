# VSMe — My Digital Playground 🎨🚀

Welcome to **VSMe** — a personal portfolio project that’s more than just a "Hello World" site.  
It’s a glimpse into how I think, design, and code — with plans to grow into something much bigger.

## 🌟 What is VSMe?

VSMe is a personal portfolio I built using [v0.dev](https://v0.dev) — an experimental AI-powered tool to rapidly prototype front-end designs.  
Currently, it serves as a showcase of my skills and projects, but in the near future, I plan to evolve it into:

- A customizable, interactive portfolio builder ✨  
- With user logins, personalization options, and responsive real-time features 🛠  
- And eventually, a product that helps other devs and creatives build their digital identity effortlessly 💡

## 🧰 Built With

- **Typescript**
- **React**
- **Tailwind**
- **Vercel** (for deployment)
- 💡 Generated UI via [v0.dev](https://v0.dev) — then refined and customized by me
